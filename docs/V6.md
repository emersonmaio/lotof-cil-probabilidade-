# V6 — probabilistic portfolio model

V6 estimates a smoothed inclusion score for each of the 25 numbers from several historical windows plus recency. It then generates candidate 15-number games and selects a portfolio of 10 while penalizing excessive overlap.

Configurations:
- V6-A: 20/50/100/200 windows, moderate recency.
- V6-B: heavier long-window weighting.
- V6-C: 10/30/75/150 windows, stronger recency.
- V6-D: V6-A scoring with stronger portfolio diversity penalty.

Selection is performed on validation 2275-3032 only. The holdout starts at 3033 and must not be used to choose the configuration.

## Multi-seed stability

src/v6_stability.py repeats the complete validation-selection/holdout-evaluation procedure with independent deterministic seeds.

For each seed:
1. all four configurations are evaluated on validation;
2. one configuration is selected using validation only;
3. that selected configuration is evaluated on the untouched holdout;
4. the result is recorded.

The holdout is therefore never used to choose a configuration. The report aggregates:
- average holdout mean-best;
- standard deviation across seeds;
- average and standard deviation of 13+ counts;
- how often each configuration was selected.

Default stability audit: 5 seeds, validation 2275-3032, holdout 3033-3794.

This is an experiment on historical data. It does not guarantee future lottery results.
