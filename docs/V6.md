# V6 — probabilistic portfolio

V6 estimates a smoothed inclusion score for each of the 25 numbers from several
historical windows plus recency. It then generates candidate 15-number games and
selects a portfolio of 10 while penalizing excessive overlap.

Configurations:
- V6-A: 20/50/100/200 windows, moderate recency.
- V6-B: heavier long-window weighting.
- V6-C: 10/30/75/150 windows, stronger recency.
- V6-D: V6-A scoring with stronger portfolio diversity penalty.

Selection is performed on validation 2275-3032 only. The holdout starts at 3033
and must not be used to choose the configuration.

This is an experiment on historical data. It does not guarantee future lottery
results.
